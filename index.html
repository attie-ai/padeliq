Run it on your Mac

Get started locally.

  1. Download and unzip the project.
  2. Install Python 3.11 and FFmpeg. The commands shown use Homebrew.
  3. Open Terminal inside the extracted PadelTrace folder and run the setup commands.
  4. Open the local app and start with a 10–20 second segment.

Installation and the first model download need internet. Videos stay in the local app. CPU is the default; select MPS to try Apple Metal.

Useful observations.
Honest limits.

Tracking IDs can switch players without warning. Review every segment before trusting its output. v0.1 estimates movement; it does not score shots, track the ball, or provide validated coaching advice.

The original recording and M3 performance have not yet been verified. Synthetic functional checks passed.

Read the practical testing plan ↗
Where do my videos go?

Load them into the app on your Mac. Uploaded recordings and generated files are stored in its local_data folder. There is no video upload form on this website.

What happens when tracking is lost?

The selected player is left unlabeled for the remainder of the segment, with blank position coordinates. Start another segment from a clear frame and select the player again. Close crossings can still cause silent swaps.

When is a heatmap defensible?

When the camera stays fixed, you can identify all four floor corners of the full court, and you have reviewed the tracking. Hidden corners, camera movement and inaccurate foot estimates can make a heatmap misleading.

Can I use it offline?

After installing dependencies and downloading the model weights, use a local weights file to process recordings offline. Test this on your Mac before relying on it.
